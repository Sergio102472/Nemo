# Nemo

Приложение обмена криптовалют.

## Механизм обмена

1. **Резерв** — пользователь выбирает валюты и вводит сумму. Приложение только резервирует данные сделки. Кошельки не трогаются. При обрыве сети до нажатия кнопки ничего возвращать не нужно.

2. **Ордер** — открывается **только** в момент нажатия «Обменять». Фиксируется точное время нажатия (квант времени) + данные сделки.

3. **Токен** — лаконичный и человекочитаемый:
   ```
   ГГГГ.ММ.ДД ЧЧ:ММ:СС.ммм | сумма FROM → сумма TO
   ```
   Пример:
   ```
   2026.08.29 09:45:12.847 | 1.5 ETH → 4800 USDT
   ```
   (год · месяц · день · час · минута · секунда · доля секунды · валюты и суммы)

4. После нажатия — мгновенный **внутренний обмен** и запись токена в архив ордеров.

## Модуль 1

- Лог действий сверху
- Два селекта валют + два поля суммы
- Живой курс со стрелками ↑↓ (тики)
- Автопересчёт суммы «получаете»
- Резерв → кнопка «Обменять» → токен
