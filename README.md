# Nemo

**Nemo** — приложение обмена криптовалют на **$mol**.

## Стек

- **$mol** (MAM)
- TypeScript
- Модульная архитектура

## Модуль 1 (текущий)

- Два селектора криптовалют (из / в)
- Поле ввода суммы
- Курс в реальном времени (обновляется каждые 5 сек)
- Информационное окошко сверху — лог всех действий и запросов (для разработки и тестирования)
- Кнопка «Обменять» внизу

При нажатии «Обменять» фиксируется квант времени (`Date.now()`), который станет ID токена/ордера.

## Запуск

1. Клонируй MAM:

```bash
git clone https://github.com/hyoo-ru/mam.git mam
cd mam
npm install
```

2. Скопируй папку `nemo/` и `index.html` из этого репозитория в корень MAM (или сделай симлинк).

3. Запусти сервер:

```bash
npm start
```

4. Открой в браузере:

```
http://localhost:9080/nemo/app/-/test.html
```

Или через `index.html` в корне (если настроен).
