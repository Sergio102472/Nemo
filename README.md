# Nemo

**Nemo** — приложение обмена криптовалют.

## Возможности

- Подключение одного или нескольких криптокошельков (демо)
- Отображение котировок валют
- Обмен между криптовалютами на основе баланса кошельков
- **Токен = квант времени**: в момент нажатия «Обменять» фиксируется точное время (timestamp), которое становится уникальным ID токена/ордера
- Внутренний обмен: средства списываются и зачисляются на подключённые кошельки
- Архив всех ордеров (токенов)

## Как работает

1. Приложение считывает подключённые кошельки и формирует список криптовалют, которыми владеет пользователь.
2. Пользователь выбирает валюту «из» и «в», вводит сумму.
3. Приложение показывает актуальный курс под полями ввода.
4. При нажатии **«Обменять»**:
   - Фиксируется **квант времени** (`Date.now()`) — это и есть токен.
   - В токене записываются: время, валюта и количество «из», валюта и количество «в», курс.
   - Происходит внутренний обмен: балансы кошельков обновляются.
   - Токен сохраняется в архив ордеров.

## UI

- Два поля ввода суммы (горизонтально)
- Над каждым полем — выбор криптовалюты
- Под полями — реальный курс
- Кнопка «Обменять»
- Карточка созданного токена + список архива ордеров

## Стек

- React + TypeScript + Vite
- Демо-кошельки (позже — WalletConnect / Web3)
- Демо-курсы (позже — CoinGecko API или DEX)
