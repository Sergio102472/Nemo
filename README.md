# Nemo

**Nemo** — приложение обмена криптовалют.

## Возможности

- Подключение одного или нескольких криптокошельков
- Отображение котировок валют
- Обмен между криптовалютами на основе баланса кошельков

## Как работает

1. Приложение считывает подключённые кошельки и формирует список криптовалют, которыми владеет пользователь.
2. Пользователь выбирает валюту «из» и «в».
3. Приложение получает актуальный курс и показывает его под полями ввода.
4. Нажатие кнопки «Обменять» инициирует обмен.

## UI

- Два поля ввода суммы (горизонтально)
- Над каждым полем — выбор криптовалюты
- Под полями — реальный курс
- Кнопка «Обменять»

## Стек

- React + TypeScript + Vite
- (в планах) WalletConnect / Web3 для кошельков
- CoinGecko API для курсов (демо)

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:5173
