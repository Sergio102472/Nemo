# Nemo

Криптообменник. Стек: **mam $mol** (+ HTML-прототип для быстрой проверки в браузере).

## Модуль обмена

- Кнопка «Выбрать валюту» + сумма (отдаёте)
- Кнопка «Выбрать валюту» + сумма (получаете)
- Оба поля ввода активны
- Комиссия **2%**

### Прототип в браузере

https://htmlpreview.github.io/?https://github.com/Sergio102472/Nemo/blob/main/prototype.html

### $mol (mam)

```bash
git clone https://github.com/hyoo-ru/mam.git && cd mam && npm i
# скопировать nemo/ в корень mam
npm start
# http://localhost:9080/nemo/exchange/
```
