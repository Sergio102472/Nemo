# Nemo

Криптообменник. Стек: **mam $mol** + HTML-прототип.

## UI модуля обмена

**Блок «Отдаёте» / «Получаете»:**
1. Строка: кнопка валюты + **баланс кошелька**
2. Строка: input суммы + **курс в реальном времени** (USD)

Комиссия **2%**. Кнопка **Обменять**.
