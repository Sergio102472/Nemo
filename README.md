# Nemo

Криптообменник. Стек: **mam $mol** + HTML-прототип.

## Механизм (не классический ордербук)

1. **Резерв** — при выборе валют и вводе суммы приложение собирает данные сделки (from, to, курс). Кошельки не трогаются.
2. **Ордер** — только в момент нажатия **«Обменять»**. Фиксируется время нажатия (квант).
3. **Токен** — человекочитаемый квант времени + данные сделки:
   ```
   мс.сек.мин.час.день.год | сумма FROM @ курс → сумма TO
   ```
   Пример: `847.12.45.09.29.2026 | 0.1 BTC @ 95000 → 9405 USDT`

## Комиссия 1%

1% с отдаваемой валюты зачисляется на **кошелёк приложения** (монетизация).

## UI

- Строка: кнопка валюты + баланс
- Строка: сумма + **текущий курс** со стрелками ▲/▼ в реальном времени
- Кнопка «Обменять»
